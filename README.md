# Engineering Portfolio

大学で取り組んだ研究および制作プロジェクトをまとめたポートフォリオです。  
人とシステムのインタラクション、実機ロボット制御、装着型デバイス制作、ユーザー体験を意識したものづくりに関する取り組みを掲載しています。

## Projects

### 1. Joint Attention Robot System

卒業研究で作成した、人とロボットの共同注意に基づくロボット応答制御システムです。  
Webカメラを用いた視線推定結果をもとに、人とロボットが同じ対象へ注意を向けているかを判定し、ロボットの応答動作を切り替えました。

- 使用技術：Python, ROS, Linux, ptgaze, UDP通信, CSVログ保存
- 担当範囲：視線データ処理、共同注意判定、ロボット制御、実験ログ保存
- 詳細：[joint-attention-robot-system](./joint-attention-robot-system)

### 2. Wearable Device Game


研究室の6週間制作プロジェクトで制作した、装着型デバイスを用いた体験型ゲームです。  
ユーザーは手足に装着したデバイスの光を手がかりに、出題されたポーズへ近づきます。

- 使用技術：Python, OpenCV, Webカメラ, 三角測量, UDP通信, BLE通信, XIAO
- 担当範囲：進捗管理、実現方法の整理、座標取得方法の検討、デバイスの基板加工

- 詳細：[wearable-device-game](./wearable-device-game)
